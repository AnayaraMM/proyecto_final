# Contexto de los Datos

## Descripción del Proyecto

Este proyecto tiene como objetivo predecir la demanda de pacientes en los servicios de urgencias hospitalarias de Castilla y León mediante técnicas de aprendizaje automático y variables externas relacionadas con la meteorología y el calendario.

La predicción se realiza a nivel temporal utilizando información histórica de actividad asistencial y datos climáticos obtenidos para cada provincia.

## Objetivo Analítico

El propósito final es anticipar la demanda asistencial en urgencias con suficiente antelación para facilitar:

- La planificación de recursos humanos.
- La gestión de cargas asistenciales.
- La optimización de turnos.
- La mejora de la capacidad de respuesta ante picos de demanda.
- El apoyo a la toma de decisiones operativas en el entorno hospitalario.
